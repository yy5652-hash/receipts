## Title

Receipts: does the source really say that? Citation audits with NVIDIA Nemotron on Nebius Token Factory

## Description

Paste an AI-written report. Receipts checks every citation against its source, quotes the proof, and finds a real source when a citation fails.

Built for the Nebius × NVIDIA Global AI Hackathon (Best Apps and Agents track) with NVIDIA Nemotron 3 Nano, Super and Ultra on Nebius Token Factory, and Tavily search and extraction.

Try it: https://receipts.43-160-214-187.sslip.io
Code (MIT): https://github.com/yy5652-hash/receipts

ReceiptsBench (300 cited sentences from 35 real sources, half with planted errors): Nemotron 3 Ultra caught 141 of 142 problems with no false alarms, at about $0.003 per claim. For claims cited to the wrong source or a dead link, Receipts found a real source for 39 of 45.
