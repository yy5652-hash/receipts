# Briefing: Honey bee and BERT: Pre-training of Deep

The genus name Apis is Latin for "bee" [1]. The pre-trained BERT model can be fine-tuned with just one additional output layer to create state-of-the-art models for a wide range of tasks [2]. A. mellifera was first domesticated before 1800 BC and was the third insect to have its genome mapped [1]. The masked language model randomly masks some of the tokens from the input, and the objective is to predict the original vocabulary id of the masked word based only on its context [2]. The non-parametric memory in RAG models is a dense vector index of Wikipedia accessed with a pre-trained neural retriever [3]. Chronic exposure to sublethal imidacloprid doses suppresses honey bee antimicrobial peptide expression, increasing pathogen susceptibility [4].

The generator in RAG is BART-large, a pre-trained seq2seq transformer with 400M parameters, and it always produces the correct output when given sufficient context [3]. BERT uses a next sentence prediction task that jointly pre-trains text-pair representations [2]. OpenAI GPT uses a left-to-right architecture where every token must attend to all previous tokens in the self-attention layers of the Transformer [2]. Chinchilla outperforms Gopher (280B), GPT-3 (175B), Jurassic-1 (178B), and Megatron-Turing NLG (530B) on a large range of downstream evaluation tasks [2].
